## Kod yazma

`len` önerisini seçtiğinizde **`len()`** eklenir ve imleç parantezin içine geçer.

```python
tasks = ["Kod yaz", "Test et", "Kaydet"]
print(len(tasks))
```

## Markdown görünümü

- **Kaynak:** Markdown metnini düzenleyin.
- **Kaynak + Önizleme:** Sonucu yazarken görün.
- **Önizleme:** İşlenmiş belgeyi okuyun.
- **HTML kaynağı:** Üretilen HTML kodunu inceleyin.
